2026-10-19

交付范围
在现有 Expo Router / 原生 Stack / retained Tabs 上做增量优化，没有重写导航。
UI、素材比例、业务规则、通知就绪判断、权限、配对隔离、提交幂等及失败恢复不变。
本轮不执行迁移，不部署 API/Admin，不发布客户端或 OTA。

根因与实际修改
1. 入口共用 pending/error 状态，已就绪目的地可能继承另一个入口的等待。
   现在就绪入口同步 dispatch；独立 intent + generation 隔离旧导航；
   同一未完成 intent 合并，超时及账号/配对变化仍阻断旧响应。
2. Affection/普通 Adventure 原先点击后创建页面。现在 Home 空闲时使用
   原生 stack.preload 分批准备；Burrow 空闲时准备 Memories Room。
   稳定 getId 只复用无额外参数的普通入口；通知任务/历史目标/参数化入口不合并。
   队列受焦点、前后台、账号代次、配对版本及业务阶段检查保护，数量有限。
   不预挂载支付/摄像头/播放器/奖励结算，Friends Room 不提前启动拜访 runtime。
3. 通知 registry 的全局 revision 会带动无关页面重画。
   改成按可见计数订阅，hidden retained model 只消费自身相关通道；
   正文就绪、版本、已读规则、实时更新/前台补查/兜底刷新不变。
4. Home 焦点、时钟、余额变化导致整个房间 element tree 重建。
   房间图层缓存稳定，动作代理始终调用最新权限/业务闭包；
   家具、照片、装扮、季节、昼夜、身份、忙碌等相关变化仍会更新。
   Home 图片准备不因 blur/focus 重做；可选解码不再阻塞已获授权的导航。
5. Affection 去掉仅为时钟而订阅完整 store 的额外依赖，保留静态页面；
   隐藏时不显示接收弹窗、不标已读；新 inbox 在打开首帧前形成接收状态。
6. AdventureReveal 不再从 JS 同步读取 UI shared value 来判断完成。
   动画完成、原速、减弱动态效果及后台恢复规则不变。
7. Release 发现 native-stack placeholder 不允许 setOptions。
   usePageBackGesture 改为有焦点才应用；隐藏 AdventureReady 不能注册返回锁。
   正式打开后已记录页面仍只允许 Start，原业务限制不变。

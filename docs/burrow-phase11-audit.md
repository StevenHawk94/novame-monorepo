# 第十一批：代码收尾检查与修复

日期：2026-09-27。针对用户要求的代码收尾，本批检查分享隐私、购买异步回调、历史编辑生命周期和旧版本写入口；修复以下可复现问题。素材继续占位，保留工作区既有修改，没有提交 Git、部署、真实付款、远程迁移或开启功能开关。

## 发现与处理

### 1. 迟到的分享请求可能重新公开已撤回的日记

原分享写入没有版本检查；另一设备的旧请求／网络重试可能覆盖最近的关闭分享。

- 迁移 `140_burrow_sharing_conflicts` 为每篇分享状态增加递增版本，写入同时验证当前伴侣、关系代次和期望版本。
- 成功命令存储幂等收据；旧成功请求重试只返回原收据，不重新执行公开操作。相同键不同参数拒绝，冲突要求刷新后重试。
- 同一伴侣解绑后重新绑定，旧代次的请求也不能继续修改隐私；历史保留规则不变。
- 新 API 从认证取作者，不信任客户端用户 ID；Moments 传递版本与请求键。旧无版本 RPC 返回升级提示，防止滚动发布期间绕过保护。
- 私密记录显示“recorded a private day”；原文卡片移除无关的 Open collection 按钮。

相关：`supabase/migrations/20260920000140_burrow_sharing_conflicts.sql`、`apps/api/src/app/api/vnext/command/route.js`、`apps/mobile/src/components/burrow/burrow-history.tsx`。

### 2. 旧任务创建／AI 与气泡奖励入口未完全停用

- 新版开启时，`bubbles/pop`、`quests/start`、`quests/custom` GET/POST 在认证后、任何旧读写／AI 前返回 410；开关读取失败不继续执行旧业务。
- 旧 quest-pick／quest-custom／quest-write-own 页面在新版重定向到当前任务页，不挂载旧页面组件。
- 迁移 `141_burrow_retired_bubble` 增加数据库层开关检查，即使旧 API 实例仍运行也不能在新版发放气泡 XP。关闭新版开关后保留原奖励和幂等逻辑。
- 包装函数及改名后的旧核心均禁止 anon/authenticated 执行，原服务端路径保留。没有删除旧数据、队列或旧功能实现。
- 补充 `tools/sql-review/burrow-retired-write-access.sql` 只读检查清单，供完整测试数据库上线前核验。

### 3. 旧付款回调可能清掉新账号／新订单状态

- 金币结账增加操作代次，所有完成／失败／超时更新必须匹配账号会话和操作代次。异步取 session、计算账号哈希后再次验证，避免账号切换期间继续打开旧结账。
- 验单单飞按会话代次隔离，旧账号的请求不会被新账号复用；旧验单失败不能清掉新结账的等待状态。
- 已持久入账的 Apple 交易仍可以结束确认，但 UI 刷新必须属于当前账号。Google 仍由服务器在入账后 consume。
- 有明确订阅商品 ID 的错误交还订阅监听器，不再被金币等待流程吞掉；另一金币 SKU 的错误不取消当前结账。
- 订阅与金币在异步准备后、占用购买状态前再次互斥检查；订阅重复点击也拦截。兑换码页在已有购买时不打开第二个系统窗口。

相关：`apps/mobile/src/lib/carrot-iap.ts`、`apps/mobile/src/lib/iap.ts`。未改变三个 coin ID、商店价格或原订阅 ID。

### 4. 后台刷新可能关闭正在编辑的回忆

- 编辑器冻结所编辑记录及其原版本；钱包／Realtime 导致历史页重新加载时不关闭编辑器，不丢掉尚未持久化的输入，也不偷偷采用另一设备的新版本。
- 即使原记录来自较早分页，刷新后仍保留原编辑基线；保存冲突仍由服务端版本检查处理。
- 列表页和编辑器均绑定本人＋伴侣＋关系代次，切换关系后不显示上一个关系的页或编辑器。
- 本修复不把分页缓存当作权限来源，也不绕过删除、解绑或版本冲突校验。

## 迁移和部署约束

1. 在独立测试库按完整前置链应用 116–139，然后 140、141；140 依赖 137 的关系代次和 138 的分享表，141 依赖历史 pop_bubble 函数。

3. 保持生产新版／新购买开关关闭，完成权限、升级、回滚、两设备隐私及商店回调验收后再安排发布。本批未执行这些线上操作。

## 剩余边界：不能据此宣称“只剩素材”

- 上述修复通过本地测试，但 PGlite 是受控夹具，不是所有历史迁移的从零重建，也不证明实际部署库没有额外函数重载、宽松 ACL 或多连接锁竞争问题。完整历史权限清单仍需在隔离测试库核验。
- 仍需确认新版 Plus 订阅商品、价格与试用配置；已确认的三个 coin ID 不等于订阅配置。
- 实际商店验单／通知、杀进程后恢复、退款、账号切换、无商品 ID 的原生错误，以及真实两设备的隐私撤回、同步、照片 Storage 与清理任务，需要沙盒和真机联调。
- 签名构建、相机／相册权限、多点手势、推送、大字体、屏幕阅读器和视觉素材替换验收仍未完成。
- Game Room 明示 coming soon，仍是既定暂缓范围；Admin 可编辑现有内容，但新增内容／审计回滚 UI 不是已交付能力。没有把这些占位或可选扩展改写为已完成。

旧第九／十批文档是各批快照；目前 coin 闭环和日记分享的开发状态以第十批及本批为准。

# 第九批核验与剩余非素材事项

日期：2026-09-27。依据工作区代码、需求 DOCX 和提供的视觉参考；素材全部继续占位。未部署、未修改线上数据库或开关、未提交 Git，也未执行真实付款／Storage 删除。

## 本批实现

1. **记录策略（131）**：新版 Free 在当日冒险开始前可以多次 Write Freely／Tap Your Day；当天出发后禁止新增，但已保存请求重试和未完成结算仍可恢复。共享 Plus、本人 AI 同意、非空文本共同决定 AI；不再受旧每日两次 AI 或三篇日记额度限制。服务器按 profile 时区决定日期；SQL 和 API 均不发旧 XP。关闭新版开关保留旧规则。status、prepare、客户端缓存和错误提示同步更新。
2. **历史（132）**：Moments／Memories 每页 30 条 keyset 分页，以创建时间＋ID 排序；同时间不漏不重。按个人时区筛选日期，提供可操作月历、All days、重试和末页提示。每页验证双向配对，过滤私有及已删除内容，照片只返回元数据；重新聚焦／前台／权威快照变化会重置历史，避免旧页长期保留已删除数据。
3. **内容后台（133）**：Admin 新增 Burrow Content 页；现有商品、朋友、对话和引导问题可读取、编辑 JSON 草稿、预览字段并确认发布。草稿版本＋当前数据 hash 防覆盖；允许字段白名单保护价格、稳定 ID、库存；发布有审计和数据库校验，失败不改变正式内容。POST 校验管理员和同源。暂不支持新增内容行或审计回滚 UI，不能把它称为完整 CMS。
4. **冒险呈现**：服务器投影时间驱动 0–1000 米展示与分段占位行程；不是实际发现事件日志，不承诺沿路奖励。物品结果两步开箱／领取，领取仍由服务端幂等执行；减少动态效果、失焦、后台停止动画。
5. **Affection（134）**：保留六种手势，加三秒等待后明确确认的无障碍路径，共用冷却／奖励／幂等。计时改用单调时间，后台和失焦取消未完成动作；过程及完成轻触感，失败可沿原操作键重试。头像与传递动画仅在服务器确认后显示已送出，尊重减少动态效果。冷却时可进入现有 Plus paywall。
6. **照片草稿（135）**：房间相框、公仔和回忆照片统一保存已裁切 JPEG base64、请求键和旧版本到本机。关闭／重启后恢复预览，用户明确 Save 才上传；失败或响应丢失保留原键。按本人＋原伴侣隔离、最多五份草稿、大小受限；服务器在 prepare 同事务验证原伴侣，不能重定向给新伴侣。草稿不是自动上传队列、云端备份或端到端加密；沿用 MMKV，退出账号会清除。已发短链仍可能使用至到期。
7. **配对生命周期（136–137）**：解绑／换伴侣取消双方未完成冒险，保留审计结果及已发放物品／余额，不退当日次数；已取消结果不再预留掉落。即使同伴重新绑定也不能结算／领取旧结果。每次真实关系变化旋转代次，bootstrap 返回 `pairVersion`；文字 outbox 和服务器写入同时核验。旧代次或无代次待发送文字只保留并提示人工查看，不能自动重放；可复制为新草稿后重新 Save。历史记录保留，未自动删除旧关系数据。
8. **入口**：恢复 Home 菜单、余额＋跳转 Carrot Shop、余额不足引导、共享房／商品 Plus 引导、商店装修入口、Home 聚合未读互动与礼物弹层。非互动装饰不再误跳装修。Paywall 新版权益文案不再提 Bunny Court／Master；现有真实商店定价／订阅购买链保留，并未改成需求中的新价格或试用。
9. **跨午夜**：以服务器时间＋单调增量、个人时区判定换日，在前台触发重新读取任务；失败最多每分钟重试，不本地伪造新奖励。
